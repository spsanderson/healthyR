# healthyR Wiki Files

This directory contains comprehensive wiki documentation for the healthyR package.

## About These Files

These markdown files are designed to be uploaded to the GitHub wiki for the healthyR repository. They provide thorough documentation covering all aspects of the package.

## How to Use

### Option 1: Upload to GitHub Wiki

1. Go to the healthyR GitHub repository wiki
2. Create/edit pages with the same names as these files (without .md extension)
3. Copy the content from each file to the corresponding wiki page

### Option 2: Automated Upload

If you have wiki access, you can clone the wiki repository and copy these files:

```bash
# Clone the wiki repository
git clone https://github.com/spsanderson/healthyR.wiki.git

# Copy files from this directory
cp wiki/*.md healthyR.wiki/

# Commit and push
cd healthyR.wiki
git add .
git commit -m "Add comprehensive wiki documentation"
git push
```

## Maintenance

### Updating the Wiki

When updating the wiki:

1. Edit the appropriate .md file in this directory
2. Test markdown rendering
3. Update cross-references if needed
4. Upload to GitHub wiki
5. Verify links work correctly

### Adding New Content

To add new documentation:

1. Create a new .md file in this directory
2. Follow the existing formatting style
3. Add navigation links at the bottom
4. Update Home.md with new page link
5. Update this README.md

### Style Guidelines

- Use clear, descriptive headings
- Include working code examples
- Add navigation links
- Cross-reference related pages
- Keep examples practical and realistic
- Include troubleshooting tips

## Testing

Before uploading to the wiki:

1. Check all internal links
2. Verify code examples work
3. Ensure consistent formatting
4. Review for typos
5. Test markdown rendering
